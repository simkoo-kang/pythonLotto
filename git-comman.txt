# 현재 내 위치와 .gitignore 생성 방법 확인하기
- VS Code 터미널에서 아래 명령어를 차례대로 입력하시면 정확한 위치에 파일을 만들 수 있습니다.
1. 현재 폴더 위치 확인하기 (결과에 lotto가 포함되어 있는지 확인)
 - Windows: cd 누르고 엔터
 - Mac/Linux: pwd 누르고 엔터
2. 정확한 위치에 .gitignore 생성 및 내용 채우기
 - 터미널에 아래 명령어를 그대로 실행하면 현재 폴더에 곧바로 파일이 생성됩니다.
 
 bash:
  echo .venv/ >> .gitignore
  echo __pycache__/ >> .gitignore


# VS Code의 탐색기(Explorer)에서 파일과 폴더를 정렬하는 방법
1. 단축키 Ctrl + , (Mac은 Cmd + ,)를 눌러 설정 창을 엽니다.
 - 상단 검색창에 Sort Order를 검색합니다.
 - Explorer: Sort Order 항목의 드롭다운 메뉴를 클릭하여 원하는 정렬 방식을 선택합니다.
2, 방법 2: settings.json 파일에 직접 입력하기
 - 설정 파일(settings.json)에 아래 코드를 추가하면 곧바로 적용됩니다. 옵션에 따라 정렬 기준이 달라집니다.
 - 마지막 부분에 [,] 입력 후 엔터, 다음에 붙혀넣기

    // 정렬 방식 선택 (아래 옵션 중 하나를 적으세요)
    "explorer.sortOrder": "default" - 파일 구분 없이 이름 순이면 "mixed"

# setting.json 열기 
1. VS Code 화면에서 단축키 Ctrl + Shift + P
 (Mac은 Cmd + Shift + P)를 눌러 명령 팔레트를 엽니다.
2. 검색창에 Preferences: Open User Settings (JSON)(또는 한국어로 기본 설정: 사용자 설정 열기(JSON))을 입력하고 선택합니다

.settings.json 파일이 편집창에 즉시 열립니다.
